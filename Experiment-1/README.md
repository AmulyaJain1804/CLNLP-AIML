# Experiment 1: Data Exploration and Visualization

This folder contains Jupyter Notebooks focused on basic data analysis, manipulation, and visualization using Python's `pandas` and `matplotlib` libraries. The experiments utilize a sample dataset representing employee information.

## Dataset
* **[employee_information_100.csv](employee_information_100.csv)**: A sample dataset used across all notebooks in this directory. Make sure this file is kept in the same directory as the notebooks.

## Lab Experiments

* **[Experiment 1.1](experiment1.1.ipynb)**: **Average Salary by Department**
  Reads the employee dataset, calculates the average salary for each department, and visualizes the result using a bar chart.

* **[Experiment 1.2](experiment1.2.ipynb)**: **Employee Count by Department**
  Reads the dataset and displays the number of employees working in each department.

* **[Experiment 1.3](experiment1.3.ipynb)**: **Gender Ratio**
  Analyzes the dataset to calculate the percentage of male and female employees and displays it using a pie chart.

* **[Experiment 1.4](experiment1.4.ipynb)**: **Salary Distribution**
  Analyzes the salary column and draws a histogram to visualize how salaries are distributed across the workforce.

* **[Experiment 1.5](experiment1.5.ipynb)**: **Experience vs. Salary**
  Creates a scatter plot to observe the correlation between an employee's years of experience and their salary.

* **[Experiment 1.6](experiment1.6.ipynb)**: **Top Earners**
  Sorts the data and displays the top 10 employees with the highest salaries in the organization.

* **[Experiment 1.7](experiment1.7.ipynb)**: **Maximum Salary by Department**
  Groups the data by department to find and display the highest salary within each specific department.

* **[Experiment 1.8](experiment1.8.ipynb)**: **Above Average Salary**
  Calculates the overall average salary of the entire organization, then filters and displays all employees earning more than that average.

* **[Experiment 1.9](experiment1.9.ipynb)**: **Average Experience by Department**
  Calculates the average years of experience of employees within each department.

* **[Experiment 1.10](experiment1.10.ipynb)**: **Age Distribution**
  Visualizes the distribution of employee ages across the organization using a histogram.

---

## How to Run
1. Navigate to this folder.
2. Start Jupyter Notebook, JupyterLab, or VS Code.
3. Open any of the `experiment1.x.ipynb` files.
4. Run the cells sequentially to see the pandas operations and matplotlib visualizations.
