# Interfaces between team members (handoff contracts)

All paths are relative to the repository root. Language codes: `en`, `as`, `mni`, `lus`, `bodo`, ...
A **pair** is always written `en-X`, for example `en-as`. A **direction** is `src-tgt`, for example
`en-as` or `as-en`. Use `src.utils.split_direction("as-en")` to get `("as", "en", "en-as")`.

## M1 → M2: raw data (`src/data/`)
```
data/raw/_original/...                 untouched downloads + checksums.json (immutable)
data/raw/{pair}/{train,dev,test}.src   English, one sentence per line, UTF-8
data/raw/{pair}/{train,dev,test}.tgt   language X, line-aligned with .src
data/raw/{pair}/stats.json             line counts per split
docs/SOURCES.md                        origin, URL, licence, counts, checksums
```
Guarantee: for each split, `.src` and `.tgt` have the same number of lines (asserted).
`data/raw/` is never edited by later stages.

## M2 → M3/M4: processed data (`src/preprocess/`, `src/eda/`)
```
data/processed/{pair}/{split}.{en,X}        cleaned, NFC-normalised text (detokenised)
data/processed/{pair}/{split}.tok.{en,X}    SentencePiece pieces (space-separated), for inspection
data/processed/{pair}/spm.model|spm.vocab   joint en+X unigram model (train split only)
data/processed/{pair}/preprocess_config.yaml  exact settings + filter counts
data/processed/{pair}/stats.json
```
- Special ids in every `spm.model`: `<pad>`=0, `<unk>`=1, `<s>`=2, `</s>`=3, plus the user symbol `<BT>`.
- Dev and test are only normalised. They are **never** filtered, so every model is scored on the
  same sentences.

## M3/M4 → M5: model outputs (`src/models/`)
```
outputs/{model_name}/{direction}/test.hyp        one detokenised hypothesis per test line
outputs/{model_name}/{direction}/dev.hyp
outputs/{model_name}/{direction}/train_log.csv   step,epoch,train_loss,dev_loss,dev_chrf,dev_bleu,lr,elapsed_s
outputs/{model_name}/{direction}/run_config.json config, seed, hardware, wall_clock_s, git_commit, finished
outputs/{model_name}/{direction}/checkpoint_best.pt   (baseline / BT only)
```
`model_name` ∈ `baseline`, `backtranslation`, `nllb_finetune`, `baseline_frac{0.1,0.25,0.5}`.
Write `run_config.json` through `src.utils.RunRecorder`. `finished: true` means `test.hyp` is complete;
the notebooks use it to skip finished runs.

**In git:** `test.hyp`, `train_log.csv`, `run_config.json` and `comet.json` for every run, plus
`outputs/synthetic/*/quality.json`. **Local only** (`.gitignore`): checkpoints, `dev.hyp`,
`zeroshot_dev.hyp`, the synthetic corpora and `outputs/logs/` (raw job output); they are
regenerated by the training commands.

Extra M4 artefact: `outputs/synthetic/{pair}/{mono.en, syn.X, quality.json}` holds the synthetic
corpus and its round-trip quality. `outputs/nllb_finetune/{direction}/zeroshot_dev.hyp` holds the
pre-fine-tuning outputs.

## M5: evaluation and reports (`src/eval/`, `src/viz/`)
```
outputs/{model}/{direction}/comet.json   {model, comet_version, system_score, segment_scores}  (GPU)
reports/results/scores.csv               model,direction,n,chrf++,chrf++_lo,chrf++_hi,bleu,...
reports/results/significance.csv         paired bootstrap vs baseline
reports/results/sentence_scores.csv      sentence-level chrF++
reports/results/learning_curve.csv
reports/results/results_table.md + signatures.json
reports/error_analysis.md, reports/results/error_categories.csv
reports/figures/{eda,results}/*.png|pdf
```
