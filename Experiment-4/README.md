6. Performs **Named Entity Recognition (NER)** using spaCy's `en_core_web_sm` model.

### Experiment 4.3: TF-IDF Analysis (Without NLP Toolkit)

**Input:** Three inline document strings (hardcoded in the notebook)

**Description:** Implements the complete **TF-IDF pipeline from scratch** across multiple documents, without using NLTK, spaCy, or any other NLP toolkit.

The program:
1. Reads/defines **multiple text documents** as input.
2. **Converts text to lowercase** and **removes punctuation** using Python's `string` module.
3. **Tokenizes** each document by splitting on whitespace.
4. **Calculates Term Frequency (TF)** for each term in each document:
   - `TF(t, d) = count(t in d) / total words in d`
5. **Calculates Document Frequency (DF)** — the number of documents containing each term.
6. **Calculates Inverse Document Frequency (IDF)** using the logarithmic formula:
   - `IDF(t) = log(N / DF(t))`
   - where `N` = total number of documents
7. **Calculates TF-IDF** for every term in every document:
   - `TF-IDF(t, d) = TF(t, d) x IDF(t)`
8. **Displays a formatted table** showing Term, TF, DF, IDF, and TF-IDF for each document.
9. **Identifies and displays the top 10 terms** with the highest TF-IDF scores per document.

**Sample Documents Used:**

| Document | Content |
|----------|---------|
| Document 1 | *"Natural language processing is a field of artificial intelligence."* |
| Document 2 | *"Natural language processing helps computers understand human language."* |
| Document 3 | *"Machine learning is an important part of artificial intelligence."* |

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Term Frequency (TF)** | How often a term occurs in a document relative to its total word count |
| **Inverse Document Frequency (IDF)** | Penalizes terms that appear in many documents; rewards rare, distinctive terms |
| **TF-IDF** | Combined score highlighting terms that are frequent in a document but rare across the corpus |
| **Named Entity Recognition (NER)** | Identifying and classifying real-world entities (persons, organizations, locations, dates) in text |
| **NER Labels** | `ORG` = Organization, `GPE` = Geopolitical Entity, `PERSON` = Person, `CARDINAL` = Number, `LANGUAGE` = Language |
