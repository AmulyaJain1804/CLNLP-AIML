# CLNLP-AIML

Lab Experiments for Computational Linguistics and Natural Language Processing.

## Contents
- Experiment-1/
	- experiment1.1.ipynb - Experiment-1.1: Read the employee dataset and display the average salary of each department using a bar chart.
	- experiment1.2.ipynb - Experiment 1.2: Display the number of employees working in each department.
	- experiment1.3.ipynb - Experiment 1.3: Display the percentage of male and female employees using a pie chart.
	- experiment1.4.ipynb - Experiment 1.4: Draw a histogram showing salary distribution.
	- experiment1.5.ipynb - Experiment 1.5: Draw a scatter plot showing the relationship between experience and salary.
	- experiment1.6.ipynb - Experiment 1.6: Display the top 10 employees with the highest salary.
	- experiment1.7.ipynb - Experiment 1.7: Find the highest salary in every department.
	- experiment1.8.ipynb - Experiment 1.8: Display employees whose salary is greater than the overall average salary.
	- experiment1.9.ipynb - Experiment 1.9: Calculate the average years of experience in each department.
	- experiment1.10.ipynb - Experiment 1.10: Display the distribution of employee ages using a histogram.
- Experiment-1/employee_information_100.csv - Sample dataset used in the notebooks

## Topics Covered
- Data loading and exploration
- Department-wise analysis
- Salary and experience visualization
- Basic statistics with Python

## Requirements
- Python 3
- pandas
- matplotlib
- jupyter

## How to Run
1. Open the notebook in Jupyter Notebook or VS Code.
2. Run the cells in order.
3. Make sure the CSV file is in the same folder as the notebook.
